# 🚀 Hire HUB – Job Portal Application

## 📌 Overview

Hire HUB is a modern full-stack job portal designed to connect job seekers with recruiters. It provides a seamless experience for searching jobs, applying, and managing applications.

---

## ✨ Features

* 🔍 Search jobs by title, location, and skills
* 🧑‍💼 User authentication (Login / Register)
* 📄 Apply for jobs
* 📊 Dashboard for users
* ❤️ Save jobs (Favorites / Watch Later)
* 🏢 Recruiter job posting (optional feature)
* ⚡ Fast and responsive UI

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS / Bootstrap
* Axios

### Backend

* Node.js
* Express.js

### Database

* MongoDB

### Other Tools

* JWT Authentication
* Cloudinary (for file uploads if used)

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/Hire-HUB.git
```

### 2️⃣ Install dependencies

Frontend:

```
cd frontend
npm install
npm run dev
```

Backend:

```
cd backend
npm install
npm start
```

---

## 🔐 Environment Variables

Create a `.env` file in backend:

```
PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
CLOUDINARY_URL=your_cloudinary_url
CLOUDINARY_API_KEY=your_cloudinary_api_kye
CLOUDINARY_API_SECRET =our_cloudinary_api_SECRET
```
